FORGE FC — BLUE & WHITE THEME UPDATE

This package contains the full site from the supplied archive with a visual-only blue-and-white theme update.

Changed:
- index.html: public site colors, cards, accent styling, and button hover/active appearance.
- admin.html: admin panel colors, form fields, tabs, and button styling.

Intentionally unchanged:
- worker.js
- wrangler.toml
- data.json
- README.md and images/README.txt

No authentication, OAuth, API, publishing, token, permission, or backend logic was intentionally changed.

Install:
1. Back up your current repository before uploading.
2. Extract this ZIP.
3. Upload the contents of the forge-fc-manager-blue-white folder to the same locations in your project, replacing index.html and admin.html with these versions.
4. Keep worker.js and wrangler.toml as-is in your deployed project. Do not redeploy or change Cloudflare Worker settings for this theme-only update.
5. Test the public site, admin sign-in, draft edits, and publish flow in your normal workflow.

Note: This is a visual CSS update based on the files you supplied. It has not been deployed to your live website.
